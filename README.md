A program that writes a short poem about agency — the power to choose and to act — to `/output/entry.txt`, for make.fun's "The poem about two agents agreeing" bounty. It writes one fixed poem, so two runs of it are identical.

## Run it

```sh
mkdir -p /output && python3 main.py && cat /output/entry.txt
```
